# ARENA - Bilgi Yarışması

ARENA, GitHub Pages üzerinde barındırılan ve APKPure üzerinde yayınlanan genel kültür ve bilgi yarışması platformudur.

## Özellikler
- **Kategoriler**: Genel Kültür ve Bilim & Teknoloji soruları.
- **Profil Ekranı**: Oyuncu istatistikleri ve güncelleme kontrol butonu.
- **Güncelleme Kontrolü**: `version.json` üzerinden canlı sürüm kontrolü.
